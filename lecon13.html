L13 — J'achète des vêtements : Verbes du 1er groupe irréguliers

Il existe 4 familles de verbes irréguliers en -ER :

ACHETERJETERESPÉRERENVOYER
Je/J'achètejetteespèreenvoie
Tuachètesjettesespèresenvoies
Il / Elle / Onachètejetteespèreenvoie
Nousachetonsjetonsespéronsenvoyons
Vousachetezjetezespérezenvoyez
Ils / Ellesachètentjettentespèrentenvoient

Type ACHETER

Verbes : (se) lever, peser, geler, achever, emmener, amener…

Type JETER

Verbes : appeler, épeler, projeter…

JETERS'APPELER
Jejettem'appelle
Tujettest'appelles
Il / Elle / Onjettes'appelle
Nousjetonsnous appelons
Vousjetezvous appelez
Ils / Ellesjettents'appellent
⚠️ Réforme orthographique : les verbes en -ELER / -ETER peuvent désormais se conjuguer sur le modèle de ACHETER (accent grave). ÉPELER → « j'épèle » et « j'épelle » sont tous les deux corrects. Exceptions : APPELER et JETER gardent uniquement la double consonne (« j'appelle », « tu jettes »).

Type ENVOYER

Verbes : envoyer, appuyer, tutoyer, employer, balayer…

ENVOYERPAYER
Je/J'envoiepaie
Tuenvoiespaies
Il / Elle / Onenvoiepaie

⚠️ Les verbes en -AYER acceptent les deux formes : je paie / je paye, ils paient / ils payent (nous/vous identiques).
